# APPBUS

APPBUS es una plataforma para la gestión y monitorización del transporte urbano en tiempo real.

## Objetivo
Permitir a empresas de transporte gestionar líneas, trayectos, paradas y autobuses, y a los usuarios consultar información en tiempo real.

## Estructura del proyecto
- `backend/`: servidor y lógica de negocio
- `frontend/`: aplicación cliente
- `database/`: scripts SQL y documentación de la base de datos
- `docs/`: documentación funcional y técnica

## Estado actual
Versión inicial del proyecto con definición del MVP, modelo conceptual y configuración base.

## Tecnologías previstas
- PostgreSQL
- Node.js
- React Native / React
